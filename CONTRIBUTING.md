# Contributing

Thanks for your interest in improving consumer-balancer.

## Development

- JDK 21+
- Build and test with the Gradle tool on your PATH: `gradle test` (from the repository root).

## Pull requests

- Keep changes focused on a single concern.
- Add or update tests when behavior changes.

## Code style

- Match existing formatting and naming in touched files.
- Prefer small, reviewable diffs over broad refactors mixed with feature work.
